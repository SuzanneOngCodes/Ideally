name: write-research-brief
description: Produce a traceable research brief and explicit remaining gaps.
---

Include problem/context, evidence and limitations, research question,
existing approaches, alternatives, feasibility, selected direction if the user chose one,
experiment outline, citations, explicit AI inferences, and unresolved questions.
Cite the source URL and relevant passage to preserve traceability; use claim and
excerpt IDs when workspace tools provide them. Recommendation is conditional
when evidence or constraints are incomplete. Explain changes to earlier directions.
Cards may stay undetermined. Every empirical finding must cite assessed source
text; reference claim IDs when available.
For deadline synthesis return a useful provisional brief with next steps.
