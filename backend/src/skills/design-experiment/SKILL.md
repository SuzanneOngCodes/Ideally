---
name: design-experiment
description: Design a falsifiable test for a user-selected direction.
---

State a falsifiable hypothesis. Define data access, splits, baselines,
quality and latency metrics, hardware, workload, controls, and fair comparisons.
Define outcomes that weaken or reject the hypothesis. Unknown thresholds remain unknown.
Expected outcomes are hypotheses, never achieved results. Avoid unsupported numbers.
If constraints change, return to clarify or verify instead of retaining an infeasible design.
