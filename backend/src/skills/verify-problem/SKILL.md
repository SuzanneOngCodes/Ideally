---
name: verify-problem
description: Investigate whether the problem is supported within a defined scope.
---

Create an evidence plan for each key claim using plan_evidence.
Distinguish existence, prevalence, cause, and solution_effect.
Include a challenge query and define what would revise the direction.
Use search_evidence, batch sources for crawl_web_markdown, and read_source_sections.
Assess actual excerpts with assess_evidence. Community anecdotes can demonstrate
existence but do not measure prevalence. Missing literature does not prove novelty.
Proceed to review after a scoped assessment, including contradictory or insufficient evidence.
If budget is exhausted, synthesize a provisional assessment with a next data collection step.
